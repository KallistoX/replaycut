Integrations C - only what is set up, plus "Add integration"

The page lists the integrations that are actually configured, one row each with the live diagnostics result and a test button. What is not set up is not on the page at all - it lives behind Add integration, a dialog that walks through the steps of that integration's own instructions: pick it, enter the server or sign in, test, decide whether Share should use it.

  • A fresh installation shows one button instead of eight cards of things it does not have. The page grows with what you use.
  • The setup wizard already asks these questions this way, with the same stepper - a second integration is set up like the first one was.
  • Turning something off is "Remove", which asks whether the credential should go too. That is clearer than a switch that leaves a password behind in the credential store.
  • The most work of the three, and the one that hides things: an integration you set up months ago is a row, but the reason it is not in the list is only visible inside the dialog.
