Connect OBS

replaycut watches the folder OBS writes replays to. Nothing in OBS is changed.

In OBS, once

  1. Turn on the replay buffer: Settings › Output › Replay Buffer - enable it, 300 s is a good length.
  2. Record as MKV: Settings › Output › Recording › Recording Format = mkv. MP4 breaks on a crash and cannot be read while OBS writes.
  3. Audio tracks in this order: 1 everything, 2 microphone, 3 game, 4 voice chat - Settings › Output › Recording › Audio Track and the mixer's Advanced Audio Properties. Only track 1 is required.
  4. A hotkey: Settings › Hotkeys › Save Replay - F9 is what the button in replaycut sends.
  5. Start the buffer in the main window (Controls › Start Replay Buffer). It stops when OBS closes.
The folder OBS writes replays to. Leaving the field saves it and replaycut starts watching it.
